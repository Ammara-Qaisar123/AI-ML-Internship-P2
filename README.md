## Task 1 — News Topic Classifier Using BERT

### Objective
Build a transformer-based NLP model to classify news headlines into topic categories using BERT.

### Technologies Used
- Python
- Hugging Face Transformers
- PyTorch
- Scikit-learn
- Google Colab

### Features
- Text preprocessing and tokenization
- BERT fine-tuning
- News classification
- Accuracy and F1-score evaluation
- NLP using transformers
