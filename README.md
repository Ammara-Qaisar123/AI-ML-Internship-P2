# Tasks Included

## Task 2 — Customer Churn Prediction Pipeline

### Objective
Build an end-to-end machine learning pipeline for customer churn prediction using Scikit-learn Pipeline API.

### Technologies Used
- Python
- Pandas
- Scikit-learn
- GridSearchCV
- Joblib

### Features
- Data preprocessing
- Feature encoding
- Pipeline creation
- Hyperparameter tuning
- Model export

## Task 4 — Context-Aware RAG Chatbot

### Objective
Develop a conversational chatbot using LangChain and Retrieval-Augmented Generation (RAG).

### Technologies Used

- Sentence Transformers
- Python

## Task 5 — Auto Tagging Support Tickets Using LLM

### Objective
Automatically classify support tickets using Large Language Models (LLMs).

### Technologies Used
- Hugging Face Transformers
- Python
- Google Colab

### Features
- Zero-shot learning
- Few-shot prompting
- Multi-label classification
- Top 3 tag prediction
